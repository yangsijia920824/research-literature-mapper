# Research Direction Map

## Synthesis Matrix

Build a matrix using dimensions relevant to the domain:

| Dimension | Examples |
|---|---|
| Research object | material, population, organism, text, platform, device |
| Intervention or method | synthesis, treatment, model, survey, experiment, analysis |
| Structure or scale | morphology, architecture, temporal scale, spatial scale |
| Mechanism | causal pathway, interaction, degradation, mediation |
| Outcome | performance, behavior, efficacy, stability, interpretation |
| Context | environment, application, demographic, historical period |
| Failure mode | bias, noise, instability, confounding, reproducibility |

Use tags to populate the matrix. Candidate combinations are prompts for investigation, not automatic topics.

## Candidate Direction Test

For each direction, ask:

1. What real problem, curiosity, or reproducible anomaly motivates it?
2. What evidence shows the problem matters?
3. What is known, disputed, or missing?
4. What can be tested with available resources?
5. What result would change understanding or practice?
6. Is the apparent gap only a terminology or search failure?
7. What adjacent field offers a transferable method or framework?

## Four Sources of Topics

- Curiosity-driven questions.
- Real-world problem-driven questions using first-principles decomposition.
- Reproducible anomalies, failures, or unexpected observations.
- Literature-derived substitutions or combinations.

Prefer the first three when available. Literature-derived combinations require stronger checks for meaning, feasibility, and real-world relevance.
