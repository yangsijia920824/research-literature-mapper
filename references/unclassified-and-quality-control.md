# Unclassified Records and Quality Control

## Residual Triage

When search-based grouping stops being productive, review remaining titles rapidly. Assign only enough status to preserve future utility:

- `specific-theme`
- `reference`
- `priority`
- `uncertain`
- `reviewed-not-needed`
- `irrelevant`
- `metadata-problem`

Do not classify a record merely to make the unclassified count reach zero.

For several hundred titles, use stable sorting and progress markers so work can resume without rereading. Add multiple relevant tags during manual review.

## Multiple Unclassified Queues

If both a global and a focused unclassified queue exist, process the one most likely to affect the current decision. Processing the global queue first can reveal rare expressions that belong in the focused branch; processing the focused queue first can produce a faster actionable result. State the chosen rationale.

## Count and Provenance Checks

- Record the fixed baseline count.
- Record parent-set counts before fine grouping.
- Log query, field scope, date, and result count.
- Distinguish physical groups from saved searches.
- Verify that group operations did not remove records from the source library.
- Expect overlaps under nonexclusive tagging; do not sum overlapping groups as if they were unique records.
- Sample records from each large or important group.
- Recheck queries after discovering new synonyms.

## Data Quality

Watch for:

- truncated source files or incomplete exports;
- missing abstracts or keywords;
- title formatting differences;
- duplicate records with author-format variations;
- false duplicate matches for generic titles;
- encoding errors;
- software search behavior involving case, spaces, punctuation, or partial words.

Use temporary groups before bulk moves or deletions. Preserve an audit trail for deduplication and major reclassification.

## Confidence Labels

Use explicit confidence when interpretation exceeds direct metadata:

- `high`: repeated, clean evidence across records;
- `medium`: plausible pattern with some ambiguity;
- `low`: tentative direction requiring abstract or full-text confirmation.
